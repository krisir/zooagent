# ADR-0010 去掉「工作空间」这一层：左栏就是助手列表，中间就是对话

- 状态：确定（取代 ADR-0008 的第 2 节外壳导航；其中「删除助手从首页卡片移到应用页头」已被 [ADR-0014](0014-destructive-structure-ops-live-in-primary-chat.md) 取代，三模式切换与默认模式已被 [ADR-0013](0013-assistant-always-left-data-toggle.md) 取代）
- 日期：2026-10-20

## 背景

界面里一直有一层「工作空间」：左栏顶部是工作空间名与切换箭头，下面是「今天 / 我的助手 / 最近打开」三个视图，助手要通过卡片网格才能打开。这套结构来自"通用后台"的心智模型，对个人用户不成立——本机就一个空间，没有可切换的对象；用户真正的心智只有两句：

1. 我有哪些助手？
2. 点开一个，就能直接跟它说话。

## 决策

### 1. 界面不再暴露「工作空间」

- 删除 `.workspace-chip`（工作空间名 + 切换箭头）、`VIEW_LABELS`（今天 / 我的助手 / 最近打开）与 `ViewKey` 视图状态。
- 顶栏只剩面包屑（主助手 / 某助手）与右侧状态（本机保存 + 模型）。
- 左栏底部账户区显示「本机」+ 模型名，不再显示工作空间名。

存储层没有改：数据仍然落在本机的一个目录（`ZOOAGENT_HOME` / 系统默认位置），但它是一个实现细节，不再是产品概念，也不出现在任何界面文案里。

### 2. 左栏 = 主助手 + 全部助手（平铺、星标置顶）

```
z zooagent
✳ 主助手            ← 创建 / 升级助手，永不读业务数据
──────────
助手 · 2        ＋
🧺 客户管理   ★
🌿 个人记账
──────────
⚙ 偏好设置
[z] 本机 / DeepSeek（AgentScope）
```

- 主助手固定在列表顶部，是唯一的「建新东西」入口（另有 `＋` 快捷开始三段引导）。
- 业务助手一个平铺列表：星标的按星标顺序在前，其余按 `updated_at` 倒序；星标仍是本地偏好（`lib/prefs.ts` 只保留 pinned，删掉 recent）。
- 列表本身就是导航，删除了首页的助手卡片网格（重复信息）。

### 3. 点助手 = 直接进入对话

- `AppPanelMode` 默认值从 `split` 改为 `chat`：点开助手直接是对话，数据页通过页头 `只看数据 / 并排 / 只用助手` 切换。
- 主助手首页（`app/PrimaryHome.tsx`，取代 `WorkspaceHome`）只保留：问候 + hero 对话 + 起步模板 + 一行边界说明（主助手不读业务数据）。
- 删除助手从首页卡片移到应用页头的删除按钮（Popconfirm），与固定、让主助手升级并列。（已废弃：见 ADR-0014，应用页面不再带删除/固定/升级按钮，结构操作回到主助手对话）

## 代价与边界

- **删掉了「最近打开」**：列表改为按 `updated_at` 排序。如果之后需要"最近"语义，应该由服务端记录访问时间，而不是继续在 localStorage 里堆一份影子数据。
- **删除入口变深**：从首页卡片的一键删除，变成必须先打开助手。这是刻意的——删除助手是真破坏性操作，不该在浏览列表时一点就没。
- **主助手首页不再是"工作台"**：没有助手卡片墙、没有日期化的看板。等 Task Engine 落地后，"今天要做什么"才会重新有内容可填。
- 截图与文档里的「工作空间 / 今天」文案需要同步（`scripts/dev/capture_ui.py` 已改为点击 `.nav.app` / `.nav.primary`）。

## 验证

- `apps/desktop && pnpm build`（tsc + vite）通过。
- 无头浏览器断言：左栏无 `.workspace-chip`；列表项为 `主助手 / 客户管理 / 个人记账 / 偏好设置`；点击助手后 `crumb` 变为助手名、`mode = 只用助手`、数据面板隐藏；切「并排」后数据列与 380px 助手栏共存；点「主助手」回到 hero，无 JS 异常。
- `backend && uv run pytest` 通过（71 个用例，后端未改动）。
