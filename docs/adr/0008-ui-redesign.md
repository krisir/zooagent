# ADR-0008 界面重构：以「对话优先」的温暖工作台替代通用后台

- 状态：确定（应用助手布局已被 [ADR-0009](0009-assistant-docked-layout.md) 取代；外壳导航已被 [ADR-0010](0010-rail-is-the-assistant-list.md) 取代）
- 日期：2026-10-20

## 背景

原型 `prototypes/zooagent-redesign.html` 验证了一个方向：产品不是"又一个后台管理系统"，而是"用一句话就能把事情办完的助手"。它用纸张底色、深绿墨色、柠檬绿点色和编辑化的排版，把主助手放在首屏正中央。

此前发布的桌面界面是典型的 antd 后台：蓝色主题、左侧扁平菜单、右侧常驻对话栏。功能都在，但它表达不出"你的业务，从一段对话开始"这件事，创建助手也只是一次普通的对话，缺少引导。

## 决策

参考原型重做界面，**参考设计语言与交互模型，不做像素级复刻**，并且所有界面都由真实接口驱动（原型里的静态假数据一律不用）。

### 1. 设计令牌统一落地

- `src/theme.ts` 定义调色板与 antd `ThemeConfig`；`src/styles.css` 用同名 CSS 变量承载布局与自定义组件。两处必须同步。
- 纸白 `#fbfcf9`、墨绿文字 `#17261f`、主色 `#1f7556`、点色柠檬绿 `#d5f36a`、乳白薄荷 `#eef5ee`；阴影与圆角偏柔和。
- 图表配色改为绿系为主 + 暖色/紫色点缀（`CHART_COLORS` 收敛到 `theme.ts`）。

### 2. 外壳

- 左侧固定窄栏：品牌 → 工作空间 → 空间导航（今天 / 我的助手 / 最近打开）→ 固定助手 → 偏好设置与账户。（已废弃：见 ADR-0010，工作空间与三个视图都删掉，左栏改为「主助手 + 全部助手」平铺列表）
- 顶栏只做定位与状态：面包屑（工作空间 / 当前页）+ 本机保存状态 / 离线提示。
- 内容区滚动，宽度上限 1200，保持原型的留白节奏。

### 3. 主助手回到首屏

- `HeroChat`：主助手就住在首页的深绿卡片里，输入框、示例问题都在原位；一旦开始对话，卡片自动切换成对话态（隐藏插画与标语），工具调用以 chip 形式逐条出现。
- 对话流逻辑抽成 `features/chat/useChat.ts`，首页 hero 与应用内抽屉共用同一套 NDJSON 流式处理、乐观消息与刷新信号。

### 4. 创建助手是三段引导，而不是一段自由对话

`CreateAssistantDrawer` 把模糊想法收敛成可执行请求：**想做什么 → 怎么帮你 → 确认开始**。前两段用选项卡 + 追问，最后一段把整理好的描述交给主助手，由真实的工具链创建应用。（已废弃：见 ADR-0012 —— 抽屉是写死的脚本，改为在主助手对话里真实澄清 + 确认创建）

### 5. 应用视图

- 声明式 UI 页面放在紧凑页头下，页头提供固定、应用助手、让主助手升级、刷新。
- 应用助手改为右侧抽屉（与创建抽屉同一视觉），在应用内随手唤起，不再常驻占宽。（已废弃：见 ADR-0009，现为与数据并排的停靠面板，可切换只看数据 / 并排 / 只用助手）
- 渲染器两处体验修正：连续的 `StatCard` 在同一行排布（不再各占一整行）；若页面首个 `Heading` 只是重复应用名，则不再渲染。

## 代价与边界

- **固定与最近打开仅存 localStorage**：这是纯展示层偏好，服务端还没有对应模型；换机不同步，清缓存即失效。
- **应用助手是抽屉而非常驻栏**：牺牲"随时可见"，换取应用页面更宽、更接近原型的编辑感。（该取舍被 ADR-0009 推翻：对话时看不见数据得不偿失）
- **「今天」还没有任务引擎**：该视图目前是问候 + 主助手 + 起步模板 + 助手列表；等 Task Engine 落地后，这里才是真正的"今天要做的事"。
- 原型中的装饰性进度条、静态数字等未照搬，避免呈现无真实来源的信息。

## 验证

- `cd apps/desktop && pnpm build`（tsc + vite）通过。
- `scripts/dev/capture_ui.py` 扩展为覆盖：首页、创建抽屉、我的助手、最近打开、设置、应用概览、各 Tab、应用助手抽屉，以及 `--hero-prompt` 的对话态；跑完无 JS 异常与控制台错误。
- `docs/screenshots/` 已用新界面重新生成。
