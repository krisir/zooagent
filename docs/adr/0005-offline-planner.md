# ADR-0005 内置离线模板规划器

- 状态：确定
- 日期：2026-10-20

## 决策

除了真实 LLM provider，内置一个确定性规划器（`agents/llm/offline.py`），覆盖：

- 记账 / 客户管理 / 待办清单 三类应用的完整创建流程（模型 → Action → 页面 → 种子数据）
- 应用助手的两类高频请求：`今天午餐花了 38 元`（写记录）、`这个月一共花了多少`（聚合）

它调用**和真实 LLM 完全相同的工具**，走相同的引擎与校验。

## 理由

1. **开箱可用**：用户不配置任何模型也能体验"描述需求 → 得到应用 → 录数据"的完整闭环。
2. **可回归**：端到端行为可以在离线 CI 中自动验证，不需要密钥、不会因模型版本漂移而 flaky。
3. **工具层的活文档**：规划器是工具契约的第一个消费者，工具改名或改 schema 会立刻暴露问题。

## 风险与边界

- 它不理解任意自然语言，只匹配关键词；未命中时会明确提示用户去配置模型，不会假装理解。
- **绝不能**把模板结果当作"AI 能力"对外宣称：界面会显示"离线模式"标识。
